> Event-driven Real-Time Notification & Chat Server supporting channels, message history, and user join/leave hooks.

---

## 🌟 Features

- **📡 Event-Driven Architecture**: Built using Node.js `EventEmitter` for low-latency dispatch.
- **💬 Room Management**: Dynamic channel joining, leaving, and targeted broadcasts.
- **📜 Message History**: Per-room event log tracking.

---

## 🚀 Quick Start

```bash
git clone https://github.com/msyahirmahmud/realtime-notification-service.git
cd realtime-notification-service
npm start
```

Run test suite:
```bash
npm test
```
